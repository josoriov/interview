# Interview Solutions

This repository stores interview practice solutions in small, separate files so
they are easy to revisit later.

Naming convention:
- `leetcode/0005_longest_palindromic_substring.py`

What to include in each solution file:
- Problem number and title
- Short summary of the approach
- Time and space complexity
- A few comments for non-obvious reasoning

Use `quicktest.ipynb` for scratch work and keep final solutions in the
problem-specific files.
